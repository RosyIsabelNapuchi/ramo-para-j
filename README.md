# Para mi J 💗

Un ramo de tulipanes que florece, una carta que se escribe sola y nuestros recuerdos.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo `ramo-para-j`).
2. Sube `index.html` y la carpeta `assets/` (botón *Add file → Upload files*, arrastra todo).
3. Ve a *Settings → Pages*.
4. En *Source* elige *Deploy from a branch*, rama `main`, carpeta `/ (root)` y guarda.
5. Espera 1–2 minutos. Tu link será: `https://TU-USUARIO.github.io/ramo-para-j/`

## Editar
- Carta: busca `const CARTA` en `index.html`.
- Frases de las fotos: busca `const CAPTIONS`.
- Fotos: reemplaza los archivos en `assets/` manteniendo los mismos nombres (foto_01.jpg ... foto_07.jpg).

## Música
Suena "Hasta dónde te quiero" desde YouTube al tocar *Abrir tu ramo*. Para cambiar la canción, reemplaza `VIDEO_ID` en `index.html` por el código del video (lo que va después de `youtu.be/`).
